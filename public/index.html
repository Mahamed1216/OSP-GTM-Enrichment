OSP GTM Enrichment — API

Serverless API + webhook receiver. The operator UI is not hosted here.

  • GET /health
  • POST /api/v1/leads/process — bearer INTERNAL_API_KEY
  • GET /api/v1/runs/{run_id} — bearer INTERNAL_API_KEY
  • POST /api/v1/drain — bearer INTERNAL_API_KEY or CRON_SECRET
  • POST /api/instantly/reply-webhook — header X-Webhook-Secret
  • POST /api/lead-source/run-scheduled — header X-Job-Secret
